# Numerical Linear Algebra II

MATLAB coursework from Numerical Linear Algebra II at the University of Arkansas.

## Assignment map

- `Homework1/` — coordinate, compressed sparse row, and diagonal matrix storage; Markov-chain experiments
- `Homework2/` — power, inverse-power, and Rayleigh-quotient eigenvalue iterations
- `Homework3/` — Arnoldi iteration and modified Gram-Schmidt
- `RPCGNR.m` — an additional iterative linear-algebra experiment

Start MATLAB in the repository root and add the relevant homework folder to the path before running an entry-point script.

```matlab
addpath("Homework2")
powerMethod
```

Rendered plots and PDFs are retained as assignment results. These files document completed coursework; reuse should follow the repository license and your institution's academic-integrity policy.
